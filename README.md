# FX FIGHTER · 真实外汇模拟终端

把 [weather-fighter](https://lolikonnn.github.io/weather-fighter/) 那套「把气温当股价看」的终端，
换成了**真外汇**：13 个货币对、在真实 ECB 日线上生成的日内路径，配一套照着零售券商写的撮合引擎
（点差、佣金、滑点、保证金、隔夜利息、强平）。10 万虚拟资金，浏览器里点开就能下单。

## 哪些是真的

* **每个交易日的收盘价是真的**：欧洲央行（ECB）欧元基准中间价，逐交易日，2022-01 至今（1200+ 个交易日）。
  来源 `api.frankfurter.dev`（ECB 镜像），`tools/build_rates.py` 抓取。
* **13 个品种全部由这张 EUR 基准表换算**：`EURUSD = USD`、`USDJPY = JPY/USD`、`GBPUSD = USD/GBP`……，
  交叉盘按两条美元腿相乘除，三角一致性 0 偏差。
* **每天收在真价上**：日内用布朗桥挂在「昨收 → 今收」之间，23:59 精确等于真实收盘。

**模拟的部分**：日内 1 分钟路径、D1 影线（历史逐日高低价无免费数据，按波动率估）、
最后一个交易日之后的收盘价（状态栏会标「模拟日」）、以及券商那套点差/滑点/隔夜息参数。

## 撮合规则（摘要）

| 项目 | 规则 |
|---|---|
| 合约 | 1 手 = 100,000 基础货币，最小 0.01 手 |
| 报价 | 买价 = 中间价 + 点差/2，卖价 = 中间价 − 点差/2 |
| 点差 | 随 UTC 时段、波动、每日结算前后 20 分钟变化 |
| 点值 | `pip × 手数 × 100000 × 报价货币兑美元汇率` |
| 佣金 | $3.5 / 手 / 单边 |
| 滑点 | 市价单按 `点差 × 0.12 × (1 + (手数/深度)^0.75 × 1.8) × |N(0,1)|`，2% 概率尾部大滑点 |
| 保证金 | 名义价值 ÷ 杠杆（1:10 ~ 1:500，品种上限另算） |
| 隔夜利息 | `名义价值 × ((r基础 − r报价) × 方向 − 0.25%) ÷ 365`，服务器 00:00 结算，周三三倍 |
| 追保 / 强平 | 保证金比例 < 100% 追保，< 50% 强平浮亏最大的一笔（市价 + 2.2 倍滑点） |
| 休市 | 周六全天、周日 UTC 21:00 前、周五 UTC 21:00 后 |

## 操作

左选品种，中选周期（M1–D1，滚轮缩放 / 拖动平移 / 双击复位），右侧填手数杠杆、市价或挂单、
按「点」设止损止盈；持仓行 `平` / `半` / `改`。
键盘 `↑` 做多、`↓` 做空、`空格` 平仓、`Esc` 撤单。账户自动存 localStorage，`⤓ CSV` 导出对账单。

## 数据自动更新

`.github/workflows/refresh-rates.yml`：每个工作日 15:40 UTC（ECB 公布后）抓一次数据，
数据有变化就提交 `rates.js`，Pages 自动重新发布，并顺带跑一遍 `tools/selftest.js`。
